3. RESOLUCIÓN DE CONFLICTOS
================================================================================

CONFLICTO                      SOLUCIÓN
──────────────────────────────────────────────────────────
Swipe back vs LazyRow scroll   Velocidad >300 dp/s + borde <50px
Long press vs Drag             Timeout 500ms + movimiento >50px
Swipe up vs LazyColumn scroll  Ángulo ~90° ±30°
Bottom sheet vs contenido      ModalBottomSheet maneja capas

Paso 3: Compilar y probar

5. PARÁMETROS CLAVE
================================================================================

edgeThreshold          = 50 px      (Píxeles desde borde)
velocityThreshold      = 300 dp/s   (Velocidad mínima)
dismissThreshold       = 30%        (Altura para cerrar sheet)
angleThreshold         = 30°        (Tolerancia ángulo)
LONG_PRESS_DURATION    = 500 ms     (Tiempo para menú)

Todos ajustables en GestureDetectors.kt

6. IMPLEMENTACIÓN POR PANTALLA
================================================================================

INICIO (InicioActivity)
├─ Long Press en AnioFeedCard
│  └─ .combinedClickable(onClick = {}, onLongClick = {})
├─ Swipe Up en ResumenGeneralCard
│  └─ .verticalSwipeGesture(onSwipeUp = {})
└─ Swipe Left/Right en StoriesRow
   └─ .horizontalSwipeGesture(onSwipeLeft = {}, onSwipeRight = {})

ASIGNATURAS (AnioScreen)
├─ Swipe Right desde borde
│  └─ .swipeBackGesture(onBack = onBack)
├─ Long Press en AsignaturaCard
│  └─ .combinedClickable(onLongClick = { showMenu = true })
├─ Swipe Up en AsignaturaCard
│  └─ .verticalSwipeGesture(onSwipeUp = {})
└─ Drag & Reorder (Premium)
   └─ .draggable(dragState, Orientation.Vertical)

BOTTOM SHEETS
├─ Swipe Down
│  └─ .swipeDismissGesture(sheetState, dismissThreshold = 0.3f)
└─ Contenido scrollea normalmente
   └─ LazyColumn funciona dentro del sheet

7. ACCESIBILIDAD - REGLA ORO
================================================================================

Ningún gesto es el ÚNICO camino a una función.
Siempre: Gesto + Botón, ambos hacen lo mismo.

Ejemplo:
  Long press abre menú → El mismo menú se abre con IconButton
